# App Controle de Aluguéis — Teste

Repositório de teste para validar a versão instalável (PWA) do Controle de Aluguéis antes de qualquer atualização no site principal.

A aplicação permite gerenciar casas, aluguéis, contas de água e luz e extratos mensais. Os dados ficam no navegador deste dispositivo, salvo quando a sincronização Supabase estiver configurada.

## Instalação no celular

- **Android:** abra o site no Chrome e escolha **Instalar aplicativo** ou **Adicionar à tela inicial**.
- **iPhone/iPad:** abra no Safari, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.

Esta é uma versão de teste; os dados e alterações podem mudar.
